# ✈️ 云端大厨 Sky Chef · 环球航线

一款受《飞机大厨》启发的**空中厨房时间管理游戏**，并融合了多款经典游戏的玩法：

| 借鉴来源 | 在本作中的样子 |
| --- | --- |
| 《飞机大厨》/《烹饪发烧》 | 点击设备制作餐食，在乘客耐心耗尽前送到座位上 |
| 《胡闹厨房》 | 食物会**烤焦**、组合菜要在备餐台上**拼装**、⛈️ **气流颠簸**时安全带灯亮起、禁止送餐 |
| 《杀戮尖塔》/《哈迪斯》 | 🌍 **环球冒险**：分支航线地图、每班航班后三选一**天赋卡**、免税店、随机事件、最终挑战「总统专机」 |
| 节奏 / 动作游戏 | 🔗 **连击**加成、🔥 **狂热模式**（收入翻倍 + 耐心冻结 + 烹饪加速） |
| 《星露谷物语》 | 有性格的乘客：商务客、会哭闹影响邻座的小朋友、送糖的老奶奶、开直播的网红、美食评论家 |
| 各类手游 | 📅 **每日航班**（固定种子 + 随机规则）、🛂 **护照印章**成就、厨房永久升级 |
| 街机评分 | 🍳 **趁热出锅**：成品刚出锅 1.8 秒内取出，再完成组装上菜可拿额外小费；要在多锅和乘客之间抓时机 |

纯 HTML + CSS + JavaScript，**零依赖、无需构建、离线可玩**。背景音乐为本地原创客舱主题曲，音效由 WebAudio 实时合成。

## 🚀 怎么运行

直接用浏览器打开 `index.html` 即可（电脑、手机都支持）。

也可以起一个本地服务器：

```bash
cd sky-chef
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 想在线玩：在 GitHub 仓库 Settings → Pages 中把分支设为发布源，访问仓库对应的 Pages 地址即可。

## 🎮 玩法

- **即取设备**（榨汁机、汽水机……）：点一下，成品直接送到点单的乘客手里。
- **烹饪设备**（咖啡机、烤肉架……）：点一下开始烹饪，完成后再点一下取出；放太久会**烤焦**，需再点一次清理。
- **组合菜**：先点「起盘」设备（面包篮、餐盘架……）在备餐台放一个盘子，再把配料加上去，完成后点击盘子送餐。
  点击空盘/未完成的盘子可将其设为「目标盘」，✕ 可倒掉盘子。
- 乘客满意离开时付款 + 小费（越快越多），连续好评叠加**连击**；攒满**狂热**条后点击 🔥 触发狂热。
- 烹饪设备刚完成时会短暂发出金色提示；趁热取出并上菜可获得额外小费。慢了也能正常送餐，但要在焦糊风险与新鲜奖励之间找节奏。
- 安全带灯亮（气流颠簸）时不能送餐，但可以继续备餐——提前规划！

**键盘快捷键**：`1`–`0` 对应设备，`Q W E R T` 对应备餐盘（`Shift`+键 倒掉），`空格` 狂热，`Esc` 暂停。

## 🗺️ 内容

- **生涯模式**：上海 🏮 → 纽约 🗽 → 巴黎 🗼 → 东京 🗻，4 座城市 × 6 班航班，共 24 关、25 道菜品，每关 1–3 星。
- **厨房升级**：每台设备单独升 3 级（烹饪设备：更快 → 双份 → 不易烤焦，并提高售价；其他设备：提高售价），外加机舱装饰（舒适座椅、氛围灯光、空乘培训、加长备餐台）。
- **城市 Boss 航班**：每城第 6 班登场一位 Boss 乘客——上海市长、华尔街大亨、米其林主评审、超人气偶像，各有特殊规则；Boss 生气离开则本班失败。
- **关卡挑战 🏅**：每关一个额外目标（零投诉、零烤焦、零浪费、连击、趁热上桌、闪电服务、贵宾满意），航班中实时显示进度，首次完成奖励星钻。
- **剧情**：周机长、林乘务长和对手主厨皮埃尔，每座城市开头、Boss 前、通关后各有几句对话。
- **星钻 💎 与关前道具**：每关首次拿到的每颗星 +1💎、每个护照印章 +3💎、首次完成关卡挑战 +2💎，起飞前可以买「开局狂热」「安神香薰」「临时餐车」。
- **环球冒险**（通关上海第 3 班解锁）：8 层分支航线，7 种节点（常规 / 风暴 / 头等舱 / 红眼航班 / 免税店 / 随机事件 / 休息室），17 张天赋卡，7 个随机事件，口碑系统，最终 Boss「总统专机」。
- **每日航班**：每天固定种子，从 8 种规则（颠簸不断、商务日、儿童节、极速登机……）中随机抽 2 种。
- **护照印章**：18 个成就。
- 首关带新手教程，每道新菜都有配方说明，游戏内可随时打开 📖 菜谱。

## 🧪 测试

```bash
node tests/sim.js
```

- 引擎单元测试：菜谱匹配、烹饪/烤焦、完整上菜流程、颠簸禁送、口碑失败、狂热、航线地图连通性。
- **星级校准**：`node tests/calibrate.js` 用机器人实测每关，按设计意图生成 `js/targets.js`（改了关卡生成或数值后重新运行）。
- **成长曲线模拟**：普通水平的机器人按顺序打生涯、赚钱就升级、没三星会重打，检查"卡关 → 升级 → 过关"的节奏。
- **难度曲线模拟**：用 4 种手速/失误率/反应时间的机器人玩家跑遍全部 24 关并打印星级表，另外模拟 20 次环球冒险——关卡数值都是据此调出来的。

## 📁 项目结构

```
sky-chef/
  index.html         入口
  css/style.css      全部样式（响应式，适配手机竖屏与电脑横屏）
  js/util.js         可复现随机数等工具
  js/data.js         食材、设备、菜谱、城市、乘客类型、升级、成就
  js/engine.js       航班模拟引擎（纯逻辑，无 DOM，可在 Node 中测试）
  js/targets.js      生涯星级目标（由 tests/calibrate.js 自动生成）
  js/levels.js       生涯关卡 / 冒险航班 / 每日航班生成（波次登机、难度曲线）
  js/run.js          环球冒险：天赋、航线地图、事件、商店
  js/save.js         本地存档（localStorage）
  js/audio.js        WebAudio 合成音效与背景音乐
  js/ui.js           UI 工具：元素构建、弹窗、飘字、飞行动画
  js/game-view.js    航班画面渲染、输入、教程、快捷键
  js/screens.js      标题、地图、升级、护照、冒险、结算等界面
  js/main.js         启动
  tests/bot.js       机器人玩家（测试与校准共用）
  tests/calibrate.js 星级目标校准
  tests/sim.js       无头测试 + 平衡性 / 成长曲线模拟
```

## Android 安装包

独立仓库： https://github.com/hezh202-hue/sky-chef

在 Releases 下载 `sky-chef-1.0.0.apk`，传到 Android 手机后点击安装，按系统提示允许当前浏览器或文件管理器安装应用。

- 应用名：云端大厨；包名：`com.hezh202.skychef`；版本：1.0.0。
- 最低 Android 6.0；目标 Android 15；使用系统 Android System WebView。
- 游戏资源内置，无网络权限，无广告、账号或服务器。字体使用系统回退字体。
- 已完成关卡的星级、金币、升级保存在本机。切后台会暂停；航班中按返回键暂停，主菜单按返回键确认退出。
- 网页版与 APK 存档各自独立；卸载或清除应用数据会删除本机存档。未完成航班不支持杀进程续玩。

### 重新打包

安装 JDK 17 和 Android SDK 35，将 `ANDROID_HOME` 指向 SDK，然后运行：

```powershell
node tests/sim.js
.\gradlew.bat :app:assembleDebug
# 测试包：app/build/outputs/apk/debug/app-debug.apk
```

提交到 main 后 GitHub Actions 会自动执行引擎测试、Android 静态检查、Android 15 模拟器离线测试，并生成未签名 APK（不能直接安装，需在本机签名）。可在 Actions 的 `sky-chef-apk` 附件下载。

签名私钥仅保存在本机，不提交仓库、不上传 GitHub Secrets。在本机构建发布版时，把 `SKY_CHEF_KEYSTORE` 设为密钥文件绝对路径、`SKY_CHEF_STORE_PASSWORD` 设为密码，再执行 `:app:assembleRelease`。以后升级必须沿用同一签名并递增 `app/build.gradle` 中的版本号。

若构建失败，先看 Actions 的首个失败步骤；`android-test-reports` 保存 Android 测试和静态检查报告。若手机提示包冲突，检查是否装了同包名但不同签名的 debug 版，勿直接卸载含有重要存档的版本。

### 来源与实现

从 `hezh202-hue/dungeon-rpg` 的 `claude/airplane-chef-game-project-lm3ggm` 分支拆分，源提交 `875f3d5`，保留 sky-chef 子目录的 Git 历史。原仓库保留迁移前副本。

Android 外壳按 [Android 官方本地内容加载方案](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content) 编写，使用 AndroidX WebKit 的 WebViewAssetLoader；只允许读取包内资源，不开放本地文件访问或 JavaScript 原生桥。Gradle 启动器来自 Gradle 官方 8.11.1 标签，构建发行包固定 SHA-256 校验值。

下载 Actions 产物后，也可以仅用 Android SDK Build-Tools 在 Windows 本机签名：

```powershell
.\scripts\Sign-Apk.ps1 -UnsignedApk .\sky-chef-1.0.0-unsigned.apk -OutputApk .\sky-chef-1.0.0.apk -BuildTools 'C:\Android\Sdk\build-tools\35.0.0' -Keystore 'D:\private\sky-chef.jks' -PasswordFile 'D:\private\password.txt'
```

脚本先检查 APK 对齐，再签名并验证证书，最后打印 SHA-256。密码通过文件读取，不放在命令参数或日志中。签名后再上传 APK 到 Releases；不要上传密钥或密码文件。
