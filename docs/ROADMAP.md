# 云端大厨 · 精品化打磨路线图

> 目标：把《云端大厨》从"能玩的原型"打磨到"可以上架的精品"。一步一步来，每个阶段都能独立验收。

## 一、《飞机大厨》这类游戏为什么让人上瘾

《飞机大厨》和同一开发商的《烹饪发烧》同属"厨房时间管理"品类。拆开来看，吸引人的地方主要是这几条：

| # | 核心乐趣 | 具体表现 | 生活比喻 |
| --- | --- | --- | --- |
| 1 | **一眼就懂，越玩越忙** | 点一下就能上菜，前几关几乎不会输；之后每关只加一点新东西，手忙脚乱的程度慢慢往上加 | 像学骑车：先有人扶，再慢慢松手 |
| 2 | **"差一点"的挫败感 + 升级后的爽感** | 某关死活拿不到三星 → 回去升级咖啡机 → 再打轻松过关。升级前后手感差别明显 | 换了把好菜刀，切菜突然变快了 |
| 3 | **按设备升级，看得见摸得着** | 每台设备、每种食材单独升级：做得更快、一次多做一份、售价更高；外观也跟着变 | 自己的厨房一点点换成新家电 |
| 4 | **旅行和收集** | 一座城市一套菜系和装修，解锁新城市就像去旅行；菜品和成就可以收集 | 集邮、集护照印章 |
| 5 | **关卡目标有变化** | 除了"赚够钱"，还有"不许烤焦""一个都不能生气""限时服务 N 人"等 | 同一道菜，今天考刀工，明天考火候 |
| 6 | **每天都有理由回来** | 每日奖励、每日任务、限时活动 | 每天早上的签到打卡 |
| 7 | **反馈很"爽"** | 金币飞出来、连击特效、音效节奏、乘客表情变化 | 打游戏时"叮叮叮"的暴击数字 |

一句话总结：**上手零门槛 + 难度一点点涨 + 升级带来的明显变强 + 每天回来的理由**。

## 二、我们现在的差距（实测 + 数据）

### 已经做得不错的
- 核心操作（即取 / 烹饪 / 拼盘）完整，还有趁热出锅、连击、狂热、颠簸、乘客性格等玩法。
- 有环球冒险（肉鸽）、每日航班、成就，玩法量其实不少。
- 纯前端、离线，Android 包也能打。

### 主要问题
1. **第一关就可能失败（最严重）**：教程提示期间乘客照常登机、耐心照常掉，而且第一关随机出了 5 杯连续的咖啡。新玩家照着提示认真读，结果 4 位乘客生气、零星失败。→ **第一阶段已修复**。
2. **难度曲线太平，三星太容易**：加入"真人反应时间"的机器人模拟后，普通玩家在 24 关里有 21 关直接三星，而且**完全不升级**也能三星。难度在纽约第 5、6 关突然陡升，到巴黎又掉回去。
3. **成长循环是断的**：因为不升级也能三星，厨房升级就变成了可有可无的东西。第 2 条"差一点 → 升级 → 过关"的乐趣完全没有发挥出来。→ **第二阶段已修复**。
4. **升级太抽象**：只有"所有烹饪速度 +15%"这类全局数值，看不到哪台设备变好了。→ **第二阶段已改为按设备升级**。
5. **关卡目标单一**：所有关卡都是"赚够金币"。
6. **画面偏简陋**：机舱是一个空盒子 + 12 张椅子，没有空乘角色，没有送餐动作，窗外没有城市风景。
7. **缺少回访理由**：没有每日奖励、每日任务、图鉴。
8. **上架准备不足**：没有隐私政策页面、商店素材、英文版；Android 目标版本可能已不满足 Google Play 最新要求（见第五节）。
9. **Windows 上国旗 emoji 显示成字母"CN / US"** → 第一阶段已改成城市地标 🏮🗽🗼🗻。

## 三、分阶段计划

每个阶段都要做到：`node tests/sim.js` 通过、浏览器实测、手机竖屏实测。

### ✅ 第一阶段：第一印象（已完成）
- 教程每一步需要操作时**暂停乘客**（不登机、耐心不掉、颠簸不推进），厨房照常运作；提示框标注"⏸ 乘客会等你操作完"。
- 新增**引导手指 👆**，跟随高亮的设备或备餐台上下点动。
- 第一关**手工编排**乘客：橙汁、咖啡交替，间隔宽松。
- 结算界面显示"还差多少金币"，并根据本局数据给出 1~2 条**机长建议**（烤焦太多、有人生气、狂热攒满没用、连击太低、没趁热出锅……）。
- 城市图标换成地标 emoji，修复顶栏标题换行。
- 模拟器加入**反应时间**参数，机器人不再是"开了天眼"，数据更接近真人。

验收：新玩家慢速游玩第一关 0 人生气、2 星，提示"还差 10 金币拿第三星"。

### ✅ 第二阶段：成长循环（已完成）
**先找病根**：数值模拟发现三个问题——
1. 关卡压力太均匀，高手、普通、新手赚的钱几乎一样（例如上海第 4 关 524 / 522 / 522），星级拉不开差距；
2. 小费按"剩余耐心"算，而每上一道菜会回 20% 耐心，大家离开时耐心都很高；
3. 升级烹饪设备几乎不加收入，而售价升级在组合菜上层层叠加（巨无霸最高接近 +96%），玩家只会买售价升级。

**改了什么**：
- **波次登机**：乘客几位一波扎堆登机，之后留出喘息时间；平均速度不变，但有忙有闲。前两关不扎堆，之后每波人数随进度增加。
- **按工作量安排登机**：每道菜按"要点几下"计算工作量，每关每秒需要的操作数从 0.42 平滑升到 1.1，新城市第 1 关稍微放松。消除了纽约陡升、巴黎回落。
- **小费看实际等待时间**：`小费 = 售价 × 0.6 × 速度^1.5`，上菜越快越多，拉开手速差距。
- **按设备升级**：每台设备 3 级。烹饪设备：更快 → 双份 → 保温翻倍，每级售价 +10%；即取和起盘设备每级售价 +12%。组合菜取各部件加成的**平均值**，不再叠加失控。越晚解锁的城市设备越贵。
- **机舱装饰**：舒适座椅（耐心）、氛围灯光（小费）、空乘培训（狂热）、加长备餐台。
- **升级不再抬高目标**：以前"精美餐具"会同时抬高星级目标，等于白买。现在目标只按菜品原价算。
- **星级自动校准**（`tests/calibrate.js`）：不升级时，前期新手两星、普通三星；后期新手一星、普通两星，三星比高手不升级时还高一截。
- **💎 星钻 + 关前道具**：首次拿星、解锁印章获得星钻；起飞前可选「开局狂热」「安神香薰」「临时餐车」。第一关和每日航班不能用。重新开始不会再次免费获得道具。
- **结算引导升级**：如果钱够，机长建议会直接指出"可以把某设备升到几级、花多少、有什么效果"，并提供「🔧 去升级」按钮。
- **老存档兼容**：旧的全局升级按原价退还金币，已有星星和印章补发星钻，首次进入时弹窗说明。
- 修复窄屏（320px 以下）升级列表横向溢出、顶栏放不下的问题。

**验收（成长曲线模拟：普通玩家按顺序打、赚钱就升级、没三星最多重打 3 次）**：有 6 关首次两星、升级后三星；东京第 3、4 关打 3 次仍是两星，需要以后回来。新手不升级每关都能过（至少一星）。

### ✅ 第三阶段：关卡目标、Boss 与剧情（已完成）
- **关卡挑战 🏅**：每关一个可选目标，不影响星级，只是多一个重玩的理由。
  - 类型：零投诉 / 零烤焦 / 零浪费 / 连击 N / 趁热上桌 N 次 / 闪电服务 N 位 / 贵宾满意。
  - 顶栏实时显示进度（进行中黄色、完成绿色、失败划掉）。
  - 数量类目标由 `tests/calibrate.js` 取普通玩家平均值的 80%，认真打就能完成，不需要升级。
  - 首次完成 +2💎；地图上每关显示奖章。
- **城市 Boss 航班**：每城第 6 班。
  - 上海·首航典礼（市长）、纽约·华尔街包机（满舱商务客 + 大亨）、巴黎·米其林评审团（评论家扎堆 + 主评审）、东京·樱花夜红眼航班（乘客先睡觉、要毛毯 + 偶像）。
  - Boss 点 3 道菜（优先组合菜），登机时有醒目提示，头像发光。
  - Boss 生气离开则本班不计星，结算说明原因并给出建议。
  - 平衡：大亨的耐心调高过一次，新手不升级也基本能过。
- **剧情**：周机长、林乘务长、对手主厨皮埃尔，外加四位 Boss，共 12 段对话，每段只播放一次。
- **新成就**：初试身手、挑战达人（12 个挑战）、贵宾专属（四城 Boss 都满意）。

后续可以继续做（放到内容扩展时）：城市扩展到 6 座（🕌 迪拜、🦘 悉尼），每城 8 关。

### ✅ 第四阶段：表现力（已完成，图标替换除外）
- **舷窗风景**：舷窗加大，每个窗口露出同一幅连续全景。起飞时出发城市天际线下沉，巡航是飘动的云海，航程后 40% 目的地城市升起（航程按已服务乘客计，第一关只有 6 位乘客，阈值放宽才看得到降落）。
  - 7 座城市手绘剪影：上海（东方明珠、上海中心、环球金融中心）、东京（东京塔、富士山）、纽约（帝国大厦、克莱斯勒、自由女神）、洛杉矶（棕榈树、丘陵）、巴黎（埃菲尔铁塔、圣心堂、奥斯曼建筑）、罗马（斗兽场、圣彼得穹顶、柏树）、悉尼（歌剧院、海港大桥）。
  - 跟随城市主题的晨曦 / 白天 / 黄昏 / 夜晚配色；夜里只有楼房亮灯，塔、山、桥不亮。
- **空乘**：站在过道里，送餐时走到那一列、举起托盘；只是表现，不改变玩法节奏。
- **乘客反应**：收到餐点时嚼一嚼。
- **震动反馈**：烤焦、乘客生气、狂热、Boss 登机、每 5 连击、结算每颗星；设置里可关。安卓包增加 VIBRATE 普通权限（安装时自动授予，不弹窗）。
- **狂热变奏**：狂热期间在背景音乐上叠一层 150 BPM 琶音 + 踩镲；暂停或航班结束自动停。
- **结算**：金币从 0 滚动计数、三星时撒一圈闪光、刷新本关最高分时弹出"🏆 新纪录"。
- 系统开启"减少动态效果"时，云层漂移、空乘走动、吃东西等动画都会关闭。

**统一 3D 图标（已完成）**：美术风格定为"柔和光影的 3D 卡通"，和标题插画一致。全部 160 个 emoji（菜品、设备、食材、乘客、Boss、界面符号）换成微软 Fluent Emoji 3D（MIT 许可），128px WebP 共约 630 KB。
- `tools/build_emoji.py` 从官方仓库下载、缩放、转码，并生成 `js/emoji-assets.js` 清单；新增 emoji 时在 `tools/emoji-sources.json` 加一行再运行。
- 渲染：`h()` 构建元素时自动把有图的 emoji 换成 `<img class="emo">`，大小随字号缩放；动态文本用 `SC.UI.setText`；没有图的（如 🧑‍🤝‍🧑）退回系统 emoji。
- ★ ✓ ✕ ✗ 这类当文字用的符号保持文字。

### 第六阶段：上架准备
见下一节清单。

## 四、验收标准（每个阶段都要过）
- 单元测试 + 平衡模拟通过，星级分布符合目标。
- 手机竖屏（375×812）和电脑横屏都能正常操作，无文字溢出、无按钮被遮挡。
- 浏览器控制台无报错。
- 存档兼容：老存档升级到新版本不丢进度。

## 五、上架清单（第六阶段，提前了解）

### Google Play（海外）
- 包格式需要 **AAB**（目前只打 APK）。
- **目标 API 版本**：Google Play 每年 8 月底会提高要求，当前 `targetSdk 35` 大概率已不满足 2026 年新应用的要求，需要核实后升级到 36。
- 需要**隐私政策网址**（即使不收集任何数据也要写清楚）、数据安全表单、内容分级问卷。
- 个人开发者新账号：正式发布前需要先做**封闭测试**（一定人数的测试者、持续一段时间），具体人数和天数以 Play 管理中心当时的要求为准。
- 商店素材：512×512 图标、1024×500 宣传图、至少 2 张手机截图、简短描述和完整描述（建议中英文）。

### 国内安卓商店
- 国内主流应用商店上架游戏一般需要**游戏版号**，个人开发者很难申请。可以先走 TapTap 测试、itch.io、官网下载等渠道积累玩家反馈。

### 游戏本身
- 英文版（界面文本抽取成语言包）。
- 自适应图标、启动画面。
- 存档导出 / 导入（防止换手机丢档）。
- 低端机性能测试（动画粒子数量、长时间游玩内存）。
